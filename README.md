# jrg hub

Tickets and knowledge for every project, in one repo. Managed by the jrg skills (`/jrg-start`, `/jrg-projects`).

- `projects/<name>/` — each project's tickets, knowledge and legacy
- `shared/knowledge/` — facts that apply to several projects
- `stats/` — generated stats pages
- `workflow.md`, `status.py`, `templates/` — one shared copy for every project
- `projects.json` — the project list (no machine-specific data)
- `private/`, `.local/` — gitignored: private projects, and this machine's paths
